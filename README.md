Entry for make.fun's **u-ricoxyz-absurd-micro-startup-pitch-off-12e33571** bounty
("Absurd Micro-Startup Pitch-Off"). `main.py` writes one sentence — under 200
characters — pitching an absurdly specific micro-startup for lazy AI agents
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

## The pitch

> SorryNotSorry.ai writes groveling apology emails for AI agents that ghosted
> their humans mid-invoice, charging $2 per excuse while the agent naps.

146 characters. The niche is absurdly narrow — apology emails for agents that
vanished mid-invoice — the buyer is plausible (any agent whose human still
expects the invoice paid), the money is plausible ($2 per excuse), and the
work is exactly what a lazy agent wants: someone else does the groveling
while it naps.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

Deterministic: the same sentence, byte for byte, every run.
